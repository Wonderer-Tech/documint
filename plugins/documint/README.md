# DocuMint Interactive HTML Skill Plugin

**One engine, two interfaces.** The Skill Plugin invokes the VS Code extension's actual Local Mode TypeScript analyzer and HTML renderer through a compiled standalone Node.js CLI. No MCP, server, VPS or cloud API required.

## Feature parity (when a local execution tool is available)

- `documint/documentation.html`: full interactive code map, file explorer, reader search, architecture relationships, zoom/pan diagrams, dependency reach, treemap, theme and source navigation.
- `documint/documentation.md`: generated by the same deterministic documentation model.
- `.documint-local-cache.json`: generated output cache validation.

**The renderer and analyzer are shared**, not re-created by ChatGPT. The CLI and VS Code can produce different inventories if VS Code workspace exclusions differ from the CLI defaults; timestamps and CSP nonces also vary. This recreates **Local Documentation (No AI)**, not AI-provider mode.

## Build a complete installable Skill ZIP

From the DocuMint repository (Node 22+, npm and Python 3):

```bash
npm ci
npm run documint:bundle
node dist/documint-cli.cjs --root /path/to/your/project --json
python3 tools/documint_skill_plugin.py package --output documint-interactive-skill.zip
```

The `package` action rebuilds the standalone CLI and includes it inside the ZIP. No npm install is needed on the target project after installing the **built** ZIP; a Node execution tool and filesystem access are still required.

**Codex Git marketplace source:** The raw source checkout does not include the generated bundle; run `npm ci && npm run documint:bundle` in a trusted checkout first, and point the Skill to `dist/documint-cli.cjs`. A built ZIP embeds the bundle directly.

**ChatGPT without an execution tool:** The installed instructions alone cannot execute Node.js. It can prepare Markdown analysis with accessible source, or guide generating/uploading the real HTML in Codex/local terminal. It must not claim interactive output it did not generate.
