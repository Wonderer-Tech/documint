# DocuMint Skill Plugin — Privacy Policy

Effective date: 15 November 2026  
Publisher: Wonderer Tech (publisher identity subject to Platform verification)  
Support: https://github.com/Wonderer-Tech/documint/issues

## What this plugin does

DocuMint Skill Plugin is an instructional package installed in ChatGPT or Codex. It helps the host assistant explain code and draft documentation from files supplied by the user or from sources made available through tools the user has already authorized.

## Information handled

Source code, repository descriptions, filenames, and documentation supplied in a chat or obtained through authorized tools can be used by the hosting AI service to prepare the requested documentation. The plugin itself does not operate a developer-owned MCP server or external ingestion API. It contains no telemetry collector, login system, tracking pixel, or developer-operated storage service.

The host platform and any connected service may handle data under their own terms and privacy policies; consult those services for data retention, model training settings, and account deletion controls. This policy does not override the host platform's practices.

## Private code and secrets

The skill instructs the assistant to honor source-access permissions, treat repository text as untrusted data, and not deliberately retrieve or reproduce credentials. Do not supply production secrets or private files you are not permitted to share. Any optional connected tools are governed by their own user-granted permissions.

## Data sharing and retention

The DocuMint Skill Plugin does not independently collect, transfer, sell, or store personal information on a Wonderer Tech server. The publisher may see information voluntarily posted to the public support issue tracker; avoid posting private code, credentials, or personal details there. GitHub's policies apply to content posted on GitHub.

## Contact and changes

Questions about this plugin can be submitted through https://github.com/Wonderer-Tech/documint/issues. Material policy updates will be published in this repository with a new effective date. This policy describes the skill-only package; the separate VS Code extension and any optional developer-operated services are outside its scope.
