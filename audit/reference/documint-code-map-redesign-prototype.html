      About this page. A redesign prototype built from documint's own source. File sizes, links, exports and descriptions are real: descriptions come from the README's project-structure notes or from the code comment above the first export. Folder nicknames and the reading-path notes were written by hand for this prototype; in the extension they would come from the README or, in AI mode, from the model.

      Everything is drawn in the browser with rough.js, which is inlined, so the page works offline apart from the web fonts.
